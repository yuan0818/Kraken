# Kraken 架构概览

Kraken 是面向 Android OS 与 App 的 UI 测试控制面。Web、控制面和节点代理位于本仓库；执行引擎、ADB、scrcpy 以及可选效果检测服务由部署者单独提供。

## 组件

| 组件 | 实现与职责 |
| --- | --- |
| Web | React、TypeScript、Vite、Ant Design；用例、任务、批次报告、设备、远控和看板 |
| API | FastAPI；业务校验、版本管理、设备租约、结果与证据接收 |
| PostgreSQL | 保存控制面业务事实、命令、启动许可、节点代次、报告与媒体 |
| 调度器 | 处理定时触发、任务排队、并发限制、设备匹配和有限重试 |
| RabbitMQ / Celery | Outbox 发布和短任务投递；不作为设备执行结果来源 |
| 节点代理 | 按 SN 调用外部引擎、上报状态、暂存待确认事件与证据、采集诊断及远控画面 |

源码分别位于 `apps/web`、`apps/control-plane`、`apps/node-agent`；共享协议位于 `packages/contracts`。HTTP 契约由 `scripts/export_contracts.py` 生成到 `contracts/generated`，前端类型位于 `packages/web-api-client`。

## 任务与执行

用例身份与内容版本分离，显式 Stable 指针决定可执行版本。测试任务是用例集合与执行配置；触发后创建独立批次，冻结模型和任务配置。每次尝试在开始授权事务中读取 Stable 并保存内容快照。

控制面以设备租约限制并发。节点在启动前取得持久化许可，重连后从控制面恢复活动工作并查询原引擎会话。状态未知或清理失败时保留占用，防止重复启动。节点运行时不以本地 SQLite 保存调度事实；本地文件只承担事件与证据补传。

执行状态、断言结论、清理状态和证据完整性独立展示。报告按批次汇总并列出每项用例的结果，可查看历史尝试、步骤截图、操作与判定，支持导出。ANR / Crash 与可选画面、声音质量结果是独立证据。

## 远控与部署

远控画面由节点采集，经控制面 WebSocket 转发，浏览器解码。控制权与测试租约互斥，执行期间不允许人工输入。远控页面提供画面、手势、系统按键及带历史记录的终端。详见[远程设备](../runbooks/remote-devices.md)。

开发环境支持 macOS；节点部署面向 Linux，提供 Compose、systemd 模板和 Podman 模拟实验室。部署入口见 [README](../../README.md) 与 [Linux 说明](../runbooks/linux.md)。标准系统安装位置由部署模板指定，外部源码位置通过环境变量配置，不依赖开发者个人目录。

默认部署模式面向可信内网：用户免登录、节点免 Token。身份认证扩展位于 `packages/identity`；数据库、消息代理密码和模型主密钥由部署者生成，不随源码发布。

## 当前边界

自动证据过期清理、跨主机高可用和实际多设备容量需要继续实现或专项验证。模拟结果不代表真机断言通过；检测模型需用独立样本校准后再作为质量门禁。

更详细的事务与协议语义见[领域模型与节点协议](domain-protocol.md)，恢复和升级见[节点运行](../runbooks/node-runtime.md)。
